DOTA BUILD HELPER - QUICK SETUP

Install DotaBuildHelper-Setup.exe and open Dota Build Helper.
Python is included. No Git, terminal or source-code download is needed.

Quick setup opens the first time; reopen it from the top of the app anytime.

1. SAVE YOUR STRATZ KEY
Click Get a key to open STRATZ. Obtain your token, paste it, then Save key.
A friend can privately share a key with permission, subject to STRATZ's terms.
Shared keys share limits. No key is included. Existing saved keys are kept.

2. CLICK CONNECT DOTA
The app locates Dota in Steam's libraries and installs the connection file.
Choose a folder only if automatic discovery cannot find a single installation.
The folder is remembered; existing helper configs are backed up.

3. CLICK LAUNCH DOTA
Close Dota first if it is running. This button starts Dota through Steam with
-gamestateintegration included for that launch. Use it each time, or add that
option once in Steam > Dota 2 > Properties > General > Launch Options if you
prefer Steam's Play button. Existing Steam launch settings are not modified.

4. TRY A BOT MATCH
Keep the helper open, select your position (1-5) and lock a hero in Dota.
Detected heroes load builds automatically. The first build is selected; click
another match row or change hero/position anytime. Find builds is the manual
fallback. Check live clock, inventory and skill status in Overlay & connection.
Config installation or a launch request alone does not confirm game delivery.

Keep the defaults initially. OCR, calibration, repositioning and shop-guide
export are optional. Borderless/windowed fullscreen is the intended mode.

MANUAL CONNECTION FALLBACK
If Connect Dota fails, use Overlay & connection > Export Dota game-state config.
Save it to <Dota installation>\game\dota\cfg\gamestate_integration.
Locate Dota through Steam > Manage > Browse local files. Create the final folder
if missing. Export from YOUR app; do not share the private connection token.
Add -gamestateintegration in Steam launch options and fully restart Dota.

EARLY BUILDS AND SWAPS
If Dota supplies your local hero during draft, three stable updates preload
a labelled draft preview. This does not confirm lock-in; strategy-time game
data confirms the hero. Missing draft data still needs manual selection.
Change hero or position in Builds to reload builds and keep that manual choice
for this match. Resume detection releases both overrides. New matches reset
the overrides. More options lets you disable draft previews or auto hero sync.
Position OCR is optional: install Tesseract with English data, calibrate only
YOUR assigned-role text under Draft role recognition, then enable it. Three
confident reads select the role. Otherwise the saved position stays selected.

BUILDS AND QUANTITIES
Patch confidence comes first, then premier events, other tournaments, pro
players and pubs, newest first within each group. This does not rank actual
team strength. The app's saved patch list may lag behind Dota updates.
The selected buy labels counts recorded, estimated or corrected. Edit quantities
saves a correction; Reset to source removes it. Tango counts are packs, not
remaining charges. The labelled two-branch estimate applies only to STRATZ.
Background checks compare the same player's STRATZ and OpenDota game when
identity is available. Check quantities lets you review mismatches; current
counts stay unless you accept the alternative. Older saved builds may ask for
a fresh lookup. Agreement still does not prove every purchase was captured.

OVERLAY
Enable Preview / reposition in Overlay & connection. Check the fit message;
move it or adjust width/text size if needed. Short screens use wider columns.
Starting buy hides at 1:00; early parts at 5:00; laning supplies at 10:00
(adjustable). The full major-item build stays visible. Try borderless window
mode if it is hidden. Pull/stack timings are approximate.
Invoker's ten recipes use default Q/W/E, then R to Invoke and D/F to cast.

OPTIONAL: DOTA SHOP GUIDE
Review the buy, then click Export to Dota shop. Save in:
Steam\userdata\<your account>\570\remote\guides
The app remembers your chosen account folder. Restart Dota after your game,
then select the Helper guide in that hero's shop. Quantities, item timings and
skill/talent notes are included. Shop guide status shows up to date, changed
or missing; export again when needed. It does not confirm Dota loaded the file
or switch your in-game guide. Check actual shop loading on your PC.

IF SOMETHING IS MISSING
Diagnostics track hero, clock, inventory, charges and skills separately.
A fresh clock does not mean item/skill data arrived. Check the config and launch
option, or re-export the config after an update. HTTP 429 means wait for the API
limit to reset; saved builds remain usable. Offline demo needs no key or game.
Optional draft-role recognition requires separate Tesseract English OCR and
calibration; manual position selection always works.

Find this again in Start > Dota Build Helper > Quick setup. See the Testing guide
for detailed checks. Setup is incomplete until the bot-game checks pass.
